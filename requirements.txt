# Bumped for PYSEC-2026-3988, 3989 and 3990, all against 3.3.1. 3989 is the
# one worth reading: with both a session cookie and an Authorization: Bearer
# header present, 3.3.0 and 3.3.1 resolve the caller from the cookie and
# ignore the bearer token, so the request runs and is audited as the cookie's
# principal rather than the identity the client presented. pip-audit prints no
# fix version for it because the advisory declares last_affected 3.3.1 rather
# than a fixed release; the text is explicit that only 3.3.0 and 3.3.1 are
# affected, so 3.3.2 is outside the range for all three.
